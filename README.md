# MQH-Chat

واجهة دردشة عربية باتجاه RTL مبنية باستخدام Next.js وTypeScript وTailwind CSS، مع وضع داكن وفاتح.

## الميزات الحالية
- إنشاء حساب وتسجيل دخول باستخدام بريد إلكتروني وكلمة مرور.
- تخزين كلمات المرور باستخدام bcrypt.
- جلسات موقعة داخل HttpOnly cookie.
- إنشاء غرف دردشة والانضمام باستخدام كود دعوة.
- إرسال الرسائل مع التحقق من عضوية المستخدم على الخادم.
- تصميم متجاوب للكمبيوتر والهاتف، مع مظهر فاتح/داكن.

## التشغيل
1. استخدم Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env` وأضف رابط PostgreSQL وقيمة عشوائية طويلة لـ `SESSION_SECRET`.
3. ثبّت الحزم: `npm install`
4. أنشئ الجداول: `npx prisma db push`
5. شغّل المشروع: `npm run dev`

## النشر على Vercel
اربط هذا المستودع بمشروع Vercel مستقل، ثم أضف `DATABASE_URL` و`SESSION_SECRET` في Environment Variables. بعد إضافة قاعدة البيانات، نفّذ `npx prisma db push` عبر بيئة تطوير موصولة بنفس قاعدة البيانات قبل استخدام التسجيل والمحادثات.

**مهم:** الحسابات والغرف والرسائل تحتاج قاعدة PostgreSQL مهيّأة. تحقق البريد الإلكتروني واستعادة كلمة المرور وإرسال الرسائل الفورية عبر WebSocket ليست مفعّلة في هذه النسخة الأولية.
